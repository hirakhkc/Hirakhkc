# Hirak Jyotish Chakra v3.2.0

Official source repository for **Hirak Jyotish Chakra**, conceived and directed by Hirak Chatterjee.

## Projects

- `android/` — Android application (`com.hirakchatterjee.jyotishchakra`)
- `windows/` — Windows 10/11 desktop application (Electron, x64 NSIS installer)

## Downloadable builds

Open the repository's **Actions** page, select **Build Hirak Jyotish Chakra v3.2.0**, and download:

- `Hirak-Jyotish-Chakra-Android-v3.2.0`
- `Hirak-Jyotish-Chakra-Windows-v3.2.0`

The workflow also runs automatically when application or workflow files are updated on `main`.
